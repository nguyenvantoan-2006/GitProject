# The Quiet Atlas — book landing page

A responsive static book landing page built with HTML, Bootstrap 5.3.3, and custom CSS. It includes the header/book overview, author, features, prices, download, reader reviews, and footer sections.

Open `index.html` in a browser. The sample chapter download is served from `assets/sample-chapter.txt`. The pricing buttons are demo anchors; no payment provider is connected.

Reference project: https://github.com/hoanv7169/bootstrap-demo
