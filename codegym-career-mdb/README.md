# CodeGym Career — Material Design landing page

Responsive single-page redesign based on the public CodeGym Career program page, using Bootstrap 4.5 and MDBootstrap 4.19.1 from the CDN links in the exercise. The page includes a responsive navbar, hero, program benefit cards, curriculum timeline, Java/PHP tracks, project showcase, student work, career support, consultation form, and footer.

Open `index.html` in a browser. The consultation form performs client-side validation and displays a demo confirmation only; it does not send personal data to CodeGym or any server. Images in the hero are loaded from Unsplash.

Content reference: https://codegym.vn/codegym-career/
