Bố cục Responsive với CSS Grid hiện đại

CSS Grid là công cụ phân vùng giao diện hai chiều (2D layout) mạnh mẽ nhất trong CSS hiện nay. Khác với Flexbox chủ yếu tập trung vào một trục (hàng hoặc cột), CSS Grid cho phép chúng ta kiểm soát đồng thời cả hàng ngang và cột dọc thông qua thuộc tính grid-template-areas.

Trên màn hình máy tính (Desktop), bố cục tự động trải rộng với Header và Navigation nằm trên đỉnh, phần thân tách làm 2 cột gồm Sidebar cố định 240px và Main Content co giãn chiếm trọn không gian còn lại (1fr), kết thúc bằng Footer ôm sát đáy trang.

Khi chuyển sang thiết bị di động (Mobile có chiều rộng ≤ 768px), Media Query sẽ tái cấu trúc lưới thành một cột dọc duy nhất (1fr), đảm bảo các thành phần hiển thị tuần tự gọn gàng mà không bao giờ bị tràn màn hình.
