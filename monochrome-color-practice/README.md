# Monochrome palette practice

This folder contains two color treatments of the supplied [Pra.zip source](https://github.com/codegym-vn/democodegym/blob/9cfdb957dc5976cce341eaa266bd2cb3b5aa8a0e/web/Pra.zip). The original HTML structure, local fonts, and image assets are preserved. Open `index.html` to choose a palette.

## Blue monochrome palette

The blue version follows the exercise values: primary `#00ADEE`, level 2 `#00B2EF`, page/banner background `#00BFF2`, preview content `#8DD7F7`, and light footer surfaces `#C6E9FA`. Body text is black; badges and buttons use the primary blue tones.

## Terracotta monochrome palette

The second version applies a separate single-hue scale: primary `#C45A12`, level 2 `#D17234`, page/banner background `#E6A36F`, preview content `#F2CEAD`, and light footer surfaces `#F9E7D5`.

Both versions retain the source's responsive breakpoints at 800px and 500px. Open either `blue/index.html` or `terracotta/index.html` directly in a browser.
