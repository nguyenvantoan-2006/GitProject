# Trello Dispatch — newsletter color practice

Two responsive newsletter versions share one Bootstrap layout and stylesheet. They differ through CSS custom properties, so the same components can be recolored without duplicating layout rules.

## Palettes

`newsletter-1.html` uses **Sea Glass** (analogous teal/green with a warm accent): primary `#226B65`, dark primary `#164F4C`, secondary `#DDEEE8`, accent `#E9A15B`, page `#EFF4F0`, paper `#FFFEFA`.

`newsletter-2.html` uses **After Hours** (analogous indigo/violet with a warm accent): primary `#44346E`, dark primary `#30224F`, secondary `#E9E2F5`, accent `#E1B95B`, page `#F2EEF7`, paper `#FFFEFE`.

The palettes were chosen using the harmony and preview workflow described by [Adobe Color](https://color.adobe.com/create/color-wheel). Both versions use dark text on light reading surfaces, with accent colors reserved for calls to action and small highlights.

Open `index.html` to compare the two versions, or open either newsletter file directly. Bootstrap 5.3.3 is loaded from jsDelivr.
